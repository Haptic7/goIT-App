# Heart iQ 🫀

**Heart iQ** is a mobile health application designed to assist users with emergency medical response, AI-driven symptom checking, facial biometric screening, and daily lifestyle management.

---

## 🌟 Key Features

* **Emergency SOS & 911 Dispatch:** One-tap emergency trigger with a countdown timer to prevent false alarms, automated local emergency services dialing, and CPR/pain-reduction guidance.
* **AI Facial Scanning:** 45-second video scan to assess biometric indicators.
* **Symptom Checker:** Interactive text-based symptom entry backed by AI preliminary analysis.
* **Diet & Lifestyle Hub:** Personalized health routines, dietary advice, and wellness tracking.
* **User Authentication:** Secure Sign-Up and Login supporting Aadhaar/Health ID integration and social auth options.

---

## 📱 Navigation Structure

All primary content screens utilize a persistent 3-button bottom toolbar for quick cross-navigation:

1. **Home Screen** (Main Dashboard & SOS)
2. **Diet & Lifestyle**
3. **Face Scan**
4. **Symptom Checker**
